# 02 · 替换指南 —— 该去改哪里、怎么改

> 目标：给每个替换点提供「文件路径 + 字段 + 图片规格 + 注意事项」。
> 路径基准：项目根目录 `portfolio-itom/`。
> 本文示例中的代码均来自当前项目现状，行号可能随改动漂移，请以字段名搜索为准。

## 0. 图片规格速查表

## 1. 走廊 / 入口

### 1.1 大标题与标语 —— `src/components/canvas/corridor/HeroText.jsx`

```jsx
const letters = useMemo(() => [
    { char: '吴', baseX: -0.43, splitDir: -0.8, delay: 0 },   // ← 名字第一个字
    { char: '桐', baseX: 0.43, splitDir: 0.8, delay: 0 },     // ← 名字第二个字
], []);

const taglineWords = useMemo(() => [
    { text: 'AI 自媒体', baseX: -0.5, splitDir: -0.9, delay: 0 },   // ← 标语词 1
    { text: '内容创作者', baseX: 0.5, splitDir: 0.9, delay: 0 },    // ← 标语词 2
], []);
```

- 替换方法：改 `char`（单字）与 `text` 字段。若名字超过 2 个字，需自行增删数组项并调整 `baseX`（两侧对称，左负右正）。
- 注意：`baseX` 决定字间距，多字时记得缩小绝对值。

### 1.2 门牌 —— `src/components/canvas/corridor/DoorSection.jsx`

- 搜索门牌文案（如「关于我 / 作品集 / 创作室 / 联系」）直接替换；每个门还有对应的 `id`/跳转房间名，**只改显示文案，别改房间 id**。

### 1.3 头像 —— `scripts/apply-avatar.mjs` + 帧图

- 有头像脚本，直接跑：把新头像放到脚本指定位置后执行 `node scripts/apply-avatar.mjs`，会重新生成 `avatar_anim/1~9.webp` 与 `avatar_window.webp`。
- 手动替换：把新图裁成正方形帧，覆盖同名文件（9 帧 + 入口画像）。

## 2. 关于我

### 2.1 里程碑文案 —— `src/components/canvas/rooms/About/AboutRoom.jsx`

```jsx
const STORY_MILESTONES = [
    { id: 'intro', position: [0, 0, -15], type: 'intro', title: '吴桐', subtitle: 'AI 设计师 · Base 长沙' },
    { id: 'awards', position: [0, 0, -55], type: 'awards', title: '奖项', subtitle: 'AI荣誉 ×1 • 校园精选 ×2 • 社会精选 ×3' },
    { id: 'journey', position: [0, 0, -95], type: 'journey', title: '旅程', subtitle: '三年设计经验，走向 AI 独立开发者' },
    { id: 'skills', position: [0, 0, -135], type: 'skills', title: '技能', subtitle: '设计 • AI 工具 • 自媒体 • 打比赛' },
];
```

- 替换方法：改 `title` / `subtitle` 即可。`position` 控制里程碑在天空中的前后位置，一般不动；`type` 控制该里程碑的组件类型（`awards` 类型渲染三张奖项卡），**不要改**。
- 奖项副标题的「×1/×2/×3」是**手写文案**，不会自动同步数据——改了 `awards.js` 的条数后要记得回来改这里。

### 2.2 奖项卡封面 —— `public/assets/about/SOTY|SOTD|SOTM(+_painted).webp`

| 文件 | 对应卡片 |
| --- | --- |
| `SOTY.webp` + `SOTY_painted.webp` | 中间卡（**AI荣誉**，点开 `awards.js` 的 `other`） |
| `SOTD.webp` + `SOTD_painted.webp` | 左边卡（**校园精选**，点开 `awards.js` 的 `sotd`） |
| `SOTM.webp` + `SOTM_painted.webp` | 右边卡（**社会精选**，点开 `awards.js` 的 `sotm`） |

- 规格：**2400×1760**（卡面 `planeGeometry 2400×1760`，`cover` 居中裁剪）。源图比例最好接近 2400/1760 ≈ 1.36，避免裁剪掉关键内容。
- 生成 webp 的命令（Node，用 sharp；**Windows 下必须先删除旧文件再写**，否则报 `Invalid argument`）：

```js
// 示例：生成中间卡封面（需 .cjs 后缀，见下方注意事项）
const sharp = require('sharp');
const fs = require('fs');
fs.unlinkSync('public/assets/about/SOTY.webp');          // 先删旧文件
fs.unlinkSync('public/assets/about/SOTY_painted.webp');
sharp('你的图.png')
  .resize(2400, 1760, { fit: 'cover', position: 'centre' })
  .webp({ quality: 90 })
  .toFile('public/assets/about/SOTY.webp');
```

### 2.3 奖项名称 / 条数 / 证书 —— `src/data/awards.js`

```js
export const awards = {
    sotd: {          // ← 左边卡（校园精选）
        title: '校园精选',
        items: [ /* 每个对象 = 一张证书：label 名称 / date 日期 / image 证书图 / url 链接 */ ],
        platformConfig: { label: '校园精选', color: '#1a1a1a', icon: '🏆' },
    },
    sotm: { /* 右边卡（社会精选） */ },
    other: { /* 中间卡（AI荣誉，SOTY 按钮打开它） */ },
};
```

- **名称**：改 `title` 与 `platformConfig.label`（两处需一致）。
- **条数**：`items` 数组长度 = 卡片角标数字。当前 `sotd=18`（校园精选：`cert-sotd-front-1~3.webp` 前 3 张 + `cert-sotd-1~15.webp`）、`sotm=3`、`other=7`（AI荣誉，图 `cert-ai-1~7.webp`）。
- **每张证书**：`label`（展示名）、`date`（中文日期）、`image`（证书小图，当前 `cert-N.webp` 占位）、`url`（点击链接）。
- 证书弹窗由 `GlobalOverlay.jsx` 的 `certificate_grid` 渲染，字段名请保持一致。


## 7. 注意事项（踩坑经验）

1. **普通图 + `_painted` 双版本必须成对**：桌面端悬停时会加载 `xxx_painted.webp` 做渐变揭示（`GalleryRoom` 还会按 `techStack` 文件名自动拼 `_painted`）。只放普通版会导致悬停时请求 404。
2. **sharp 在 Windows 上无法覆盖已存在的 .webp**：报 `Invalid argument`。必须先 `fs.unlinkSync(...)` 删除旧文件，再 `toFile` 写入。
3. **Node 脚本后缀**：项目 `package.json` 是 `"type": "module"`。脚本用 `import` 语法 → `.mjs`；用 `require` 语法 → **必须 `.cjs`**，否则报 `require is not defined`。
4. **中文字体换行**：`GalleryRoom.jsx` 的卡片描述已加 `overflowWrap="break-word"` 处理长中文，别删；文案里避免超长无空格字符串。
5. **改数据后角标自动变**：奖项卡角标数字 = `items.length`，无需改组件。
6. **改了没反应？** 先确认改对了文件：
   - 创作室 → 必须是 `src/data/studioContent.js`（`contentData.js` 不生效）
   - 奖项 → `src/data/awards.js`（`InfiniteSkyManager.jsx` 里的 `AWARDS_DATA` 只是兜底）
7. **新增纹理记得登记** `src/config/texturePreloadList.js`，避免首屏闪烁。
8. **别把文件复制进 `customize/` 目录**——那只是文档文件夹。
9. **图片实体在 `public/assets/<区域>/`**：改图请直接覆盖对应区域的同名文件（参考 `assets-index.md`）。原 `public/textures/`、`public/images/` 下的同名旧文件是备份，一般不引用（不要改错地方导致「改了没反应」）。
10. **生成脚本输出位置**：`scripts/apply-avatar.mjs`、`scripts/generate-placeholders.mjs` 输出到 `public/textures/`、`public/images/placeholders/`（原始位置）。运行脚本重新生成素材后，需把新文件**同步复制**到 `public/assets/` 对应区域，代码才会生效。
