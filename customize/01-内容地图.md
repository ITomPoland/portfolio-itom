# 01 · 内容地图 —— 哪里是什么

> 目标：**不读代码也能定位**每个站点位置的内容改动点。
> 阅读方式：按「区域 → 文件 → 控制的内容 → 关联图片」逐层查找。
> 路径基准：项目根目录 `portfolio-itom/`（若你当前在 `customize/` 目录，请在前面加 `../`）。

站点结构：**入口/走廊**（Home）有四扇门 → **关于我** / **作品集** / **创作室** / **联系** 四个房间。

```
┌────────────────────────────────────────────────────────┐
│  入口 / 走廊 (Home)                                    │
│   ├─ 大标题「吴桐」+ 标语「AI 自媒体 · 内容创作者」    │
│   ├─ 四扇门：关于我 | 作品集 | 创作室 | 联系            │
│   └─ 走廊尽头画像（头像动画帧）                        │
├── 关于我 (About)：天空漫步，4 个里程碑 + 3 张奖项卡     │
├── 作品集 (Gallery)：4 张可翻转项目卡片 + logo 墙        │
├── 创作室 (Studio)：6 个悬浮屏幕（视频/文章/短视频）     │
├── 联系 (Contact)：海上小岛，5 个社交桶 + 写信表单       │
└── 全局：SEO 元信息 / 无障碍层 / 成就系统                │
└────────────────────────────────────────────────────────┘
```

## 6. 全局（SEO / 无障碍 / 成就 / 预加载）

### 6.1 SEO

| 文件 | 控制内容 |
| --- | --- |
| `index.html` | 页面 `<title>`、meta description/keywords/author、**Open Graph**（`og:url`/`og:image` 仍是 `https://example.com/`，需替换）、**Twitter Card**、底部 `sr-only-seo` 隐藏 SEO 正文（大量「吴桐」文案，搜索引擎可见） |
| `src/hooks/useDocumentMeta.js` | `ROOM_META`：5 个虚拟路由（`/`、`/about`、`/gallery`、`/studio`、`/contact`）各自的标题与描述（全部含「吴桐」，换人需批量改） |
| `seo-plugin.js`（根目录） | Vite SEO 插件：构建时生成/注入每页 meta（会读取 `projects.js` / `studioContent.js` / `awards.js`） |
| `public/robots.txt` | 爬虫规则（内含站点地址，建议更新） |
| `public/sitemap.xml` | 站点地图（内含 `example.com` 域名，需替换） |
| `public/_headers` / `public/_redirects` | Cloudflare Pages 头与重定向规则（通常无需改） |
